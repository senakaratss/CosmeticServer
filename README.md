# CosmeticServer

CosmeticServer, kozmetik ürünleri için geliştirilmiş **ASP.NET Core Web API** projesidir. Angular tabanlı frontend uygulaması ile birlikte çalışacak şekilde tasarlanmıştır.

## 🛠️ Technologies

* **ASP.NET Core 8 Web API**
* **C#**
* **Entity Framework Core**
* **SQLite**
* **RESTful API**
* **DTO**
* **Entity Framework Core Migrations**
* **Swagger / OpenAPI**

## 📌 Features

* Category CRUD işlemleri
* Product CRUD işlemleri
* About içerik yönetimi
* Contact information yönetimi
* Contact message işlemleri
* Testimonial / referans yönetimi
* Testimonial görünürlük güncelleme
* Entity Framework Core ile veritabanı işlemleri
* DTO kullanımı ile veri transferi
* Swagger üzerinden API testleri

## 🗄️ Database

Projede **SQLite** ve **Entity Framework Core** kullanılmaktadır.
Veritabanı dosyası (`.db`) `.gitignore` içerisinde tutulduğu için repository'ye dahil edilmemiştir.
